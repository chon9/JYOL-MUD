> 來源：四組已查證的名單（射鵰三部曲、笑傲＋天龍、其餘小說、遊戲內已有人物與門派弟子）合併去重；遊戲資料以 `data/npcs.json`、`data/monsters.json`、`data/martial_arts.json`、`data/art.json` 為準（本文件產生時逐一核對過）。
> 本文件只是設計與名冊，**不是**資料檔；實作時照第 4 節的做法轉成資料。美術需求在 `docs/ART_REQUEST.md` 第 13 節。

## 4. 成名絕技怎麼變成資料（設計，尚未實作）

### 4.1 原則

1. **每位人物至少一門成名絕技**。被招募成隊友時，絕技排在他的 `arts` 第一位，AI 隊友會優先用（`ROGUE_PLAN` §4.2 `_ally_basic` 已經用全部 `arts`）。
2. **沿用優先**：絕技名稱與遊戲裡已有的武功相同（或已標明對應，例如虎爪絕戶手＝`wd_huzhao`）就直接引用既有 id，不另建。第 2 節「沿用」欄就是這個對照。
3. **新絕技一律新增 `rg_` 開頭的武功列**，放在 `data/martial_arts.json`，`era: "rogue"`（只在試煉世界啟用，不會出現在 MUD 世界），`sect_id: ""`、`requires: []`、`self_study_until: 0`。
4. **同名合併**：幾位人物共用的絕技只建一列，id 取名冊裡第一位使用者（例如降龍十八掌 `rg_guojing_1`，洪七公、蕭峰也引用它）。
5. `monster_only`：只當對手、不能被招募的單位用的列設 `true`；**能當隊友的人物用的絕技一律 `false`**（隊友在我方，介面要能顯示招式、武功卡也可能抽到它）。v1 建議全部 `false`，但**不放進武功卡池**（卡池只抽門派武功），絕技只跟著人物走。

### 4.2 欄位對照

| 名冊欄位 | 武功列欄位 |
|---|---|
| 絕技類型（掌、拳爪、指） | `category: "FIST"`，`base_skill: "basic_fist"`；`flavor` 用既有的掌、爪、指動畫 |
| 劍、刀、棍杖、鞭索、暗器、內功、輕功、醫、毒 | 同名 `category`（SWORD、BLADE、STAFF、WHIP、HIDDEN、INNER、LIGHTNESS、MEDIC、POISON） |
| 音律 | `category: "INNER"`、`aoe: "AROUND"`；新 `flavor: move_music`（之後配音波特效） |
| 奇技（被動、陣法、召喚） | 不做成招式：新增 `rg_traits` 小表（`{id, name, kind: PASSIVE|AURA|ONCE, params}`），掛在人物上，由試煉戰鬥規則讀取；陣法類可用既有 `category: "FORMATION"` |
| 效果構想裡的範圍（直線、3x3、周圍 1 格、扇形） | `aoe`：`LINE`、`CROSS`／`CROSS_L`、`AROUND`、`FAN`；格數放 `range` |
| 中毒、內傷、流血、封穴 | `status`：`poison`、`inner_wound`、`bleed`、`paralysis`（封穴；或用既有 `acupoint` 欄），`status_chance` 0.3–0.6 |
| 減速、暈眩、致盲、冰凍、混亂、封招、吸內力 | 目前沒有這些狀態。v1 先降級：減速／冰凍→`paralysis` 機率低一點；暈眩→`paralysis`；致盲、混亂、封招→`qixue`；吸內力→`cost_inner` 負值或 `inner` 欄。之後要做再在 `ROGUE_PLAN` 開新狀態 |

### 4.3 三段招式＝三種強度

每門 `rg_` 絕技放三招（`moves`），用 `unlock_level` 分出三種強度，同一列就能給隊友、精英、首領共用：

| 招式 | `unlock_level` | 誰用得到 | `power` 參考 |
|---|---:|---|---|
| 第一式（基本） | 1 | 凡、良隊友；一般對手 | 同類別門派武功第二招左右（約 30–40） |
| 第二式（成名招，例如「亢龍有悔」） | 60 | 稀以上隊友；精英對手 | 約 45–60，附狀態 |
| 第三式（首領版，例如洪七公「連發三段」） | 120 | 只有首領、傳說首領，以及珍、神隊友 | 約 65–85，範圍較大或附兩種效果 |

- 人物身上的等級：隊友 = 卡片稀有度對應（凡 40、良 60、稀 80、珍 110、神 130）；對手依 `RogueFoes` 的縮放；首領固定 ≥ 120，所以首領一定用得出第三式。
- 第二門絕技（名冊裡有兩門的人物）：首領兩門都帶；隊友只帶第一門，第二門在稀有度「珍」以上才帶。被動類（奇技）一律跟人物走。
- 數值最後用平衡模擬調；上表只是起點。

### 4.4 人物列

- 已有 NPC／怪物 id 的人物：試煉用的怪物列直接引用（`RogueAlly.spec_for` 讀 `monster`，有 `npc` 就借名字與立繪）；只缺戰鬥數值的，新增 `m_rg_<id>`（`era: "rogue"`），`npc` 指回原本的 NPC id。
- 沒有 id 的人物：新增 `m_rg_<id>`，名字、`desc` 用名冊；戰鬥圖用 `unit_rg_<id>`，在 `data/art.json` 登記；圖還沒來之前 `alias` 到同定位的通用圖（例如女劍客借 `emei_f`、番僧借 `m_xd_guard`），`placeholder` 照舊。
- 建議一張小表 `data/rogue_roster.json`（`era: "rogue"`）：`{id, name, novel, role, tier, monster, signature: [art ids], traits: [...], line}`，`RogueDraw`／`RogueFoes` 從這裡抽人，不必掃整個 monsters 表。名冊裡每位的台詞可以從原始查證資料搬過來，招募和首領出場時顯示。
