## 0. 選定要模仿的版本

原作介面至少有三個版本，彼此差異很大：

| 版本 | 特徵 | 證據 |
|---|---|---|
| A. 2001 早期 | 底部是淺色骨／石雕框；4 支直立玻璃瓶量表（綠紅黃藍）；戰鬥圓鈕 14 顆，放左上 | 巴哈姆特 2001 截圖 battle_4、battle_5【原作證實】 |
| B. 台版中華網龍 | 5 個燈籠是右上角**橫排**的黃色吊牌；精氣與神內分兩欄；指令列在左下 2×4 | chinesegamer 官方圖解 `images/jy-2/1.jpg`【原作證實】 |
| C. 2018 至尊服 | 右緣**直排**圓燈籠 5 顆；4 條橫向能量條；底部青銅雕木框；戰鬥圓鈕 18–19 顆，放右上 | 官方標註圖 official_main_hud_annotated、battle_6【原作證實】 |

**本作採用 C 的版面骨架，並去掉至尊服專屬元素**。理由：

- C 的官方標註最完整，每個元件都有名稱和快捷鍵，可以照著實作。
- 去掉的元素：右上 拍／商／儲 金幣鈕、截圖鈕。它們屬於至尊服商城，不屬於 1.0 核心。

A 的「直立瓶量表」可以留作以後的替換外觀（`ui_skin = "early2001"`）【推測：不是 M1 範圍】。

**本作與原作的根本差異**：原作的世界畫面是等角地圖，本作的世界是文字 MUD 加場景面板（GDD §11.1）。所以畫面上半部（「場景區」）的內容是本作自己設計的【推測】；只有外框、HUD、浮層、視窗套用原作風格。

## 1. 解析度與縮放

- 原作客戶端是 800×600（4:3），視窗模式要求 16 位元色【原作證實：qqnjy_1 量到 797×597，扣掉視窗邊框；16 位元色出自百度知道的回答，未複核】。
- 本作基準是 1280×720（`project.godot` 已設定 `canvas_items` 加 `expand`）。所有尺寸以 720 高為基準，大約是原作像素 × 1.2【推測】。
- 縮放規則：
  - 底部 HUD：錨定下緣，左右撐滿全寬。左區和右區寬度固定，中區吸收多出來的寬度；熱鍵格數維持 8 格不變。
  - 燈籠欄：錨定右上。
  - 聊天浮層：錨定左上。
  - 場景區：佔據剩下的空間。
  - 比 16:9 更寬或更窄時，`expand` 會多給空間，全部由場景區吸收。
- 最小可用視窗大小是 1024×576。低於這個大小時，靠 `canvas_items` 整體縮小，不另外改版面。
- 系統選單加「介面縮放」三段（0.9／1.0／1.15），改的是 `get_tree().root.content_scale_factor`。這是 GDD §11.4 輔助功能的一部分【推測】。

## 4. 視窗框：程式產生的九宮格

### 4.1 原作外觀【原作證實】

外框由外到內三層：

1. 玉石色大理石外框，四角有方形釘飾。
2. 橘紅與金色的編繩紋。
3. 深橄欖色、斑駁的內場。

右上角有一個 ⊠ 關閉鈕。

**不是所有視窗都一樣**：裝備窗是玉石框，屬性窗是琥珀色框，商店窗是捲軸框（見 §8）。

### 4.2 產生方式【推測：本作做法】

新增 `ui/theme/ui_frame.gd`（`class_name UiFrame`）：

- 在 `_static_init` 或第一次使用時，用 `Image.create(96, 96, false, FORMAT_RGBA8)` 逐像素畫出貼圖，轉成 `ImageTexture`，包成 `StyleBoxTexture`。
- `texture_margin_* = 24`，`axis_stretch_horizontal/vertical = AXIS_STRETCH_MODE_TILE`。邊上的繩紋要用平鋪，拉伸會變形。
- `content_margin = 26`。
- 結果依種類存在 static 字典裡，只畫一次。
- 程式裡的所有隨機雜訊都用固定 seed，讓每次產生的外觀一致。

各層像素規格（單位 px，在 96×96 貼圖上）：

| 層 | 範圍（由外往內） | 畫法 |
|---|---|---|
| 外描邊 | 第 0 px | `#14140C` 實線 |
| 大理石框 | 1–8 | `FastNoiseLite`（`TYPE_SIMPLEX`，frequency 0.18，seed 固定）的值映射到 `JY_JADE_DARK → JY_JADE → JY_JADE_LIGHT` 三段漸層；第 1 px 的上緣和左緣疊 25% 白（高光），第 8 px 的下緣和右緣疊 30% 黑（陰影） |
| 角釘 | 四角 0–13 的正方形 | `JY_GOLD` 底；外圈 1 px 斜面（左上 `JY_GOLD_LIGHT`、右下 `JY_BRONZE`）；中心 4×4 `JY_WOOD_DARK` |

## 5. 字型

只有 `assets/fonts/LXGWWenKaiTC-Regular.ttf`（OFL）已經安裝，`UiTheme.find_font()` 會優先選它。

- 原作內文是約 12 px、無反鋸齒的點陣明體【原作證實】；標題和按鈕是毛筆行楷／隸書風【原作證實】。
- 本作全部先用 LXGW WenKai TC。楷體的筆意接近原作標題；內文比原作「軟」，可以接受【推測】。
- 想更接近原作的內文，可以另外加 Noto Serif TC（OFL，明體系，GDD §11.4 已列入），只給內文用。不加也能正常運作【推測】。
- 不要模擬點陣字：在 1280×720 下，點陣小字的可讀性太差【推測】。

## 15. 實作順序建議

1. `ui_theme.gd` 色票加 `ui_frame.gd`，然後先套到 `ui_dialog.gd` 和各面板。這一步沒有版面風險，馬上就能看出風格變化。
2. 能量條改原作配色（`status_bar.gd`）。
3. `main_screen.gd` 改版面：底部 HUD、燈籠、聊天浮層、場景卷軸、小地圖移位；拆掉 `action_bar.gd`，新增 `hotbar.gd` 和 `command_panel.gd`。
4. NPC 對話、商店購物車、武功書頁、裝備人形。
5. 戰鬥（等等角戰鬥工作流程完成後）：上半部化、蜂巢圓鈕、配色、浮層戰報、自動返回。
6. 游標、音效（選用）。

## 16. 驗收清單

- 1280×720 截圖與 `official_main_hud_annotated.png` 並排比對：燈籠位置、HUD 三區比例、浮層位置一致。
- 1920×1080 與 1024×576 下沒有元件重疊；字不小於 12 px（實際像素）。
- 能量條顏色順序是 綠、紅、黃、藍。
- 戰鬥中：移動是綠格、攻擊是藍格、殺傷是紅格；游標是黃框；逃跑格是白框加逃字；兩列圓鈕可以拖曳，拖曳後的位置重開遊戲仍然記得。
- 專案裡沒有任何來自 `ui_refs/` 的圖檔：用 `git status` 和 `assets/` 目錄檢查。
- 現有無頭測試（`tests/run_tests.gd`）全部通過；有 UI 結構斷言的測試（如果有）要同步更新。測試結束後關閉 Godot 程序。
