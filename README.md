## 第一次開啟

```bash
# 在乾淨的 checkout 上先匯入資源（建立 .godot/）
godot --headless --path . --import
```

## 存檔放在哪裡（不寫 C:）

遊戲的所有本機資料（`worlds/` 世界與角色、`profiles/` 本機身分、`passports/` 角色護照、`map_memory/` 大地圖探索、`settings.json`、`logs/` 記錄檔）都放在**資料根目錄**。
決定順序（`core/util/data_root.gd`）：

1. 命令列 `--data-root=<資料夾>`（絕對路徑，或相對於下面「錨點資料夾」的路徑；`user://…` 也接受）。
2. 錨點資料夾裡的 `data_root.txt`：**匯出版＝.exe 同一層，開發／編輯器執行＝專案根目錄**。第一個非空、非 `#` 的行就是資料根目錄（相對路徑＝相對於 `data_root.txt` 所在資料夾）；
   可另寫一行 `test=<資料夾>` 指定測試根目錄（預設＝資料根目錄旁邊的 `testdata/`）。
3. 都沒有（或指定的資料夾不能寫）→ Godot 的 `user://`（Windows：`%APPDATA%\Godot\app_userdata\JY-Mini OL\`）。

| 執行方式 | 資料根目錄 | 測試根目錄 |
|---|---|---|
| 正式版 `K:\Project\JY-Mini-OL-Release\JY-Mini OL.exe`（`data_root.txt`＝`userdata`） | `K:\Project\JY-Mini-OL-Release\userdata\` | — |
| 開發／編輯器（專案根目錄 `data_root.txt`＝`../JY-Mini-OL-Work/userdata`） | `K:\Project\JY-Mini-OL-Work\userdata\` | `K:\Project\JY-Mini-OL-Work\testdata\` |

- **備份**：關掉遊戲，把整個資料根目錄（例如 `JY-Mini-OL-Release\userdata\`）複製到別處；還原＝複製回來。最重要的是 `worlds\<世界>\` 與 `profiles\`（角色綁在本機身分上，兩個要一起備份）。
- **重新匯出正式版**（`powershell -ExecutionPolicy Bypass -File tools\export_release.ps1`）只換 `.exe／.pck／.dll／txt`，**不會刪除或覆蓋 `userdata\`**（匯出前後比對雜湊，變了就報錯），已存在的 `data_root.txt` 也保留。
  匯出時 Godot 編輯器的 `APPDATA／LOCALAPPDATA／TEMP` 指到 `K:\Project\JY-Mini-OL-Work\godot_home\`，編輯器也不寫 C:。
- **給朋友（可攜版）**：把 `JY-Mini-OL-Release` 資料夾**扣掉 `userdata\`** 複製給朋友（`userdata\` 裡是你的身分與存檔，朋友用你的身分會衝突）。
  要把**角色**或**整個世界**給朋友，見下面「M3c2」的「帶走角色」「把整個世界給朋友」兩段（匯出的角色檔在 `userdata\exports\`）。
  朋友放在任何可寫的地方（例如 `D:\Games\JY-Mini OL\`）雙擊 .exe，第一次執行會在旁邊建自己的 `userdata\`。不要放在 `C:\Program Files`（不能寫入時會退回 `%APPDATA%`）。
- 引擎本身：`project.godot` 關掉了 Godot 內建的記錄檔（`debug/file_logging`，只能寫 `user://`）與著色器快取（`rendering/shader_compiler/shader_cache/enabled`）；
  記錄檔改由 `FileLog` autoload 寫到 `<資料根目錄>/logs/godot.log`（有視窗時；headless 的測試輸出在主控台或協調器的 `--log-file`）。
  Godot 啟動時仍會**建立空的** `%APPDATA%\Godot\app_userdata\JY-Mini OL\` 資料夾，有視窗時另建空的 `shader_cache\` 子資料夾（引擎行為，專案設定關不掉），但裡面不會有任何檔案。
- 2026-10-19 以前的 `%APPDATA%` 內容（含舊的 `_test\`）已整包搬到 `K:\Project\JY-Mini-OL-Work\appdata_old\`（只搬移、不刪除）。

## 怎麼玩 M1

```bash
# 單機（最常用）：直接進角色選擇
godot --path . -- --no-steam --offline --world=my_world
# 或不帶參數開啟，在標題畫面選「單機」
godot --path .
```

1. **創角**：取名、選性別、擲骰 7 項屬性（可無限重擲，每項 13–25）、把 5 點自由點數分配完、選生日月份與出生城（西夏或大理；1.0 開服只有這兩座城）。
   新手建議把自由點數加在**臂力**：臂力太低（13–15）時打野兔每下只有 1–3 點。
2. **主畫面**（仿原作客戶端，見 `docs/AUTHENTIC_UI_SPEC.md`）：左下場景卷軸有出口（移動）、人物（點名字對話 → NPC 編號選項：商店／學藝／任務／驛站／記錄點，數字鍵 1–9 直接選）、屍體與生活技能；可拖動。
   右緣燈籠 武功 `Ctrl+1`、屬性 `Ctrl+2`、裝備 `Ctrl+3`、指令 `Ctrl+4`、系統 `Ctrl+5`（中國結收合燈籠）；任務 `Ctrl+6`、地圖 `Ctrl+M`／`M`；走路 `W`／`A`／`S`／`D`（北／西／南／東，兩鍵同按走斜向：`W+A` 西北、`W+D` 東北、`A+S` 西南、`S+D` 東南；打字或對話視窗開著時不走）；`Esc` 先放開聊天框、再關視窗、最後收合燈籠。
   底部 HUD：圖示（食水錢狀善學戰，滑鼠移上去看數值）、精（綠）氣（紅）神（黃）內力（藍）、地點牌、曆法牌、熱鍵 F1–F8（預設 修煉內力／回氣／查看／回精／回神）與 Alt+1–8（物品）、頻道鈕＋聊天輸入、殺氣、系統訊息框。
   指令窗或裝備窗用滑鼠右鍵把東西拖到熱鍵格；左上是聊天／系統浮層（系統窗可開關頻道、清除、調音樂音量）。
3. **世界**（照原作 2001 開服的地理，見 `docs/WORLD_2001.md`）：一整片連續的野外，城與城之間**用走的**，野外每一步都可能踩地雷遇敵。
   1.0 只有西夏（西北）與大理（西南）兩座城；京城是 1.0B（神鵰大俠，2001-09-28）的內容。**新世界預設開 1.0A＋1.0B**（M3b），所以預設世界有京城、也可以在京城出生；`--eras=1.0A` 或 `--rule-preset=classic_strict` 的新世界沒有。
   **驛站只管「驛站送信」**：在驛站接信，自己把信走到目的地的驛站交付。坐馬車是【設計提案・非原作】的伺服器選項，預設關（`--stagecoach=on` 才開）。
   建議路線（也是驗收 bot 走的路）：
   - 西夏：武介山接「大兔皮」任務 → 東門找查小鏞設記錄點 → 出東門到西夏郊外踩地雷練功（野兔、大野兔、野狼）→ 交大兔皮。
   - 小溪邊釣魚、胡楊林砍柴；氣不夠就回客棧休息（要錢）或原地等自然回復，餓了渴了在客棧買饅頭、清水；野外的茶棚與綠洲也能住宿。
   - 驛站送信到**大理**：西夏東門 → 荒草坡 → 小溪邊 → 往南過溪口、沙丘 → 大漠邊緣 → 綠洲（可住宿）→ 河川古道 → 過石橋 → 大理北門 → 大理驛站。
     大理：陶耘稻田種田（種稻任務）、客棧學廚師做白飯。
   - 往東走官道到**少林**拜師（男性）：西夏東郊（礦坑）→ 黑龍潭 → 恆山山麓（茶棚）→ 華陰道 → 華山腳下（往北上**華山**，先過岳不群的考驗再拜師）
     → 華山水塘 → 嵩山古道（茶棚）→ 少室山腳 → 少林山門；學佛法、基本內功、少林長拳；齋堂在卯／午／酉時開飯。
   - 西夏東郊礦坑往北是血刀洞口，進去是**血刀洞迷宮**（小鬼，最深處是鬼王）。
   - 世界參數（新建世界）：`--eras=1.0A` 只開 1.0 開服內容（預設是 `1.0A,1.0B`；既有世界保留存檔裡的 era，主機可在伺服器設定打開 1.0B、下次開服生效）；`--stagecoach=on|off` 新建或既有世界都可以切換，會存進世界的 `options.json`。
4. **戰鬥**：12×8 格子 ATB；白框「逃」字格是逃跑格，移動綠格、攻擊範圍藍格、目標紅格。等待模式（預設開）下輪到你時右上兩列圓盤才會亮：移、攻、武（選招式與成數 1–10）、防、休、裝、逃（快捷鍵 1–7；可右鍵拖動圓盤）；戰報在左上浮層，時間棒清單在系統窗「特殊開關」打開。戰鬥結束約 2.5 秒自動返回（任意鍵立刻返回）。
   逾時沒下指令會自動「防」。野兔氣低於 30% 會往逃跑格跑，逃掉的怪物沒有獎勵。
   **查看偵察**（【設計提案・非原作】，GDD 5.10）：在野外按「查看」（F3 或指令窗「行動」）會仔細查看四周，跳出「你發現附近有：野兔 ×2」，
   選「迎戰」（Enter）就像踩到地雷一樣開打（同房的隊友一起），「離開」（Esc）就什麼都不發生；不用再在兩個房間之間來回走。
   偵察後 6 秒（時間倍率 ×2 時 3 秒）才能再偵察，按鈕顯示「查看（5 秒）」；城裡等安全的地方查看沒有冷卻。主機可在「伺服器設定」關掉（`scout_enabled`）。
5. **死亡**：依世界規則（預設 `classic_standard`）：實戰 ≤ 500 的新手不受罰；老手最高的一門特殊武功降 1 級、身上裝備留在屍體裡（30 分鐘內可自己撿回），在記錄點以一半精氣神重生。
6. **存檔**：主機每 60 秒自動存檔，離開時也會存；角色在 `<資料根目錄>/worlds/<世界>/characters/<身分>/`（見上方「存檔放在哪裡」）。

### 規則預設（死亡規則）

新建世界時可用 `--rule-preset=<id>` 指定 `data/rule_profiles.json` 的預設（**只影響新建的世界**，既有世界沿用存檔裡的規則）：

| id | 死亡規則 | 內容 |
|---|---|---|
| `classic_standard`（預設） | STANDARD | 新手（實戰 ≤ 500）不受罰；老手最高特殊武功 −1 級、裝備進屍體；屍體 30 分鐘 |
| `later_official` | STANDARD | 同上，但屍體只有 10 分鐘本人保護期，之後公開（30 分鐘消失）、叛師基本功減半 |
| `classic_strict` | STRICT_2001 | 每門非生活技能 −1 級、背包與裝備全部進屍體，沒有新手保護 |
| `friends_casual` | CASUAL | 只扣 10% 銀兩，武功與物品不變、沒有屍體 |

### 跟朋友一起玩（M2）

主機也是玩家；朋友加入後在同一個世界裡各自創角。**主機離線時世界凍結**（`host_offline_policy: FROZEN`）：世界時間、屍體倒數、PK值遞減都停住，主機重開同一個世界後一切照舊；
朋友的畫面會顯示「主機已離線，江湖凍結」，標題畫面有「重新連線」。開房的人（本機玩家）就是管理員。

**區網／直連（ENet）**：標題畫面「區網開房」／「區網加入」，或用參數：

```bash
# 主機（埠要在路由器／防火牆開 UDP 24565；同一台電腦測試用 127.0.0.1）
godot --path . -- --no-steam --enet-host --port=24565 --world=friends --profile=host
# 朋友
godot --path . -- --no-steam --enet-join=<主機IP>:24565 --profile=guest
```

**Steam（AppID 480 Spacewar，好友限定大廳）**：

1. 兩邊都先登入 Steam（不同帳號、互為好友），**先開遊戲**。
2. 主機在標題畫面按「Steam 開房」（不勾「公開」＝只有好友能加入）→ 進角色選擇後在系統窗（Ctrl+5）「累計上線時間」頁或標題畫面按「邀請好友」開 Steam 覆蓋介面邀請。
3. 朋友在 Steam 接受邀請（遊戲已開時會自動離開目前的世界、存檔後加入；480 冷啟動可能開成 Spacewar，見 GDD 12.3），或從 Steam 好友清單「加入遊戲」。
   勾「公開」開的房也能在「搜尋大廳」找到（版本不同的大廳會灰掉）。
4. 斷線或主機關閉後，標題畫面的「重新連線」會回到上一次的房間（ENet 位址或 Steam 大廳）。

**遊戲裡怎麼一起玩**（左下場景卷軸點玩家名字開選單）：

| 想做的事 | 操作 |
|---|---|
| 組隊 | 點名字 →「組隊邀請」；對方畫面跳出提示（60 秒內接受／拒絕）。隊伍框在右上小地圖下方：★領隊、所在地、戰鬥中；領隊可「領」（移交）、「踢」；人人可「離隊」。上限 5 人 |
| 一起打 | 隊友同房且閒著時，遇敵、找 NPC 開打、守衛戰會一起被拉進戰鬥（一場最多 8 名玩家）；晚到的隊友在卷軸上按「加入戰鬥」。實戰與學點依 1/√人數 分給勝利時還站著的人，掉落與銀兩歸最後一擊者 |
| 聊天 | 聊天框左邊的頻道鈕：千里傳音、傳音入密（填對象名字）、輕聲細語（預設，同房）、門派、組織（尚未開放）、隊伍、江湖謠言（匿名）；管理員多「天外飛仙」（系統窗「頻道開關」裡不能關）。標「（耗水）」的頻道每句 1 點水，口渴說不出話 |
| 叫戰 | 點名字 →「叫戰」，對方同意才開打；不加 PK 值，擊殺只有兩個當事人收到消息。只能在可 PK 的野外（城裡、華山、少林不行） |
| 強制 PK | **連結鍵 + 點玩家名字**（預設 Ctrl；系統窗「特殊開關」可改 Alt／Shift）→ 確認「確定要對 X 強行出手？」。新手（實戰 < 500）不能被強制 PK；擊殺 PK值 +1（每 30 分鐘上線時間 −1）、殺氣 +100、善惡 −10（殺惡人 +10）；善惡變負或 PK值 > 3 進出城有守城官兵；守衛戰不拉隊友（可 `battle_join` 自願加入），並廣播全服「【江湖傳聞】」（【設計提案】） |
| 守城官兵 | PK值 > 3 或善惡 < 0 的人進出城會被守城官兵攔下開打（很強，打不過就逃） |
| 屍體 | 死後屍體留在死亡地點：前 10 分鐘只有本人與授權者能翻（在屍體視窗「允許某人翻動」，最多 4 人，視窗列出已允許的人），之後誰都能翻，30 分鐘消失；可整個拿或一件一件拿 |
| 飛鴿傳書 | HUD 右下「鴿」：寫給任何角色名，對方不在線也收得到（上線時提醒、鴿章閃爍） |

**攻擊 NPC**（連結鍵＋點 NPC 名字，預設 Ctrl；同強制 PK）：

- 只有研究有記載的 NPC 能動手（城市居民、小孩、黃狗、羊、採礦師、街頭惡霸、城門守衛、武館教頭、門派知客／守門、星宿門人、血刀弟子、武當弟子、丁春秋、血刀老祖；名單 M3C_PLAN §5.2）。師父、商人、任務給予者、記錄點、驛站、錢莊、鏢局、看守、遊蕩惡人都受保護：只在訊息列說「X不是你能動手的對象」。
- 先跳確認框（「動手／再想想」），寫出要一個人面對幾個人、善惡殺氣變化、會不會招來官兵、善惡變負以後進出有官兵的城都會被追打、門派後果。一般居民與動物被殺後暫時消失（居民、小孩、採礦 3 時辰，動物、守衛 1 時辰，惡人 6 時辰；1 時辰 = 遊戲 2 小時；伺服器選項 `npc_respawn_pct`）；師父、門派與劇情 NPC **永遠不會消失**（打的是另一組戰鬥單位，任務與教學不受影響）。
- 每殺一個結算一次：城市居民 善惡 −10／殺氣 +10、小孩 −20／+20、小動物 −3／+2、守衛 −5／+10、惡人 +10。殺 NPC 不加 PK值。城裡殺善良或中立的人會立刻招來 1 名守城官兵（殺守衛 2 名）。

  `classic_strict` 照 2001 規則（news_4-2「善惡度為負…只要進城就會被城中守衛追殺」），新手一樣挨打。

打獵這條在 30、50 級幾乎不賺（最划算的是直接賣皮革，皮衣不比皮革多賺）——這是照研究「獵人 71 還沒有看到賺錢的曙光」留著的（擁有者決定 O14）；其他鏈都照「可以賺錢、比打怪少一點」。

比較基準：10 級＝打山豬 156 兩／小時、30 級＝打鬼 1063、50 級＝打山賊頭目約 12400。**每條製作鏈在 30、50 級時，最划算的都是做出來的成品**（`balance_sim econ_hourly` 檢查），
每個配方每花 1 點精的加值都在打獵基準的 0.3–1.5 倍之間（`econ_chain`，超出就不通過）。高等級成品比較耗精（例：菜飯 22、焦炭 20、棉襖 58、冷凝劍 140）。
打獵：每次精 13，野味／獸皮／豬肉 15 級、兔皮 11 級才剝得下來；打獵一場的時間和打怪用同一個模型（行動數 × 2 秒＋60 秒），10 級每小時約 134 兩（0.86 倍，不再比打山豬多）。
製作窗每個配方右邊兩欄：缺什麼（紅字），以及淡色小字「收購價約 N 兩（材料約 M 兩）」，每列對齊。種子（麻、棉）不收購。

**帶走角色（給朋友的說明）**：

1. **匯出**：角色選擇畫面，每個角色那一列有「匯出」。按下會把角色存成檔案
   `<資料根目錄>\exports\<名字>_<世界>_<日期-時間>.jychar.json`（正式版是 `JY-Mini-OL-Release\userdata\exports\`），畫面下方寫出路徑、可按「開啟資料夾」。
2. **把檔案給朋友**（任何方式：Discord、隨身碟…）。一個檔案約 5–10 KB。

- 數值截到這個世界的合法範圍（屬性每項 13–30、總和 ≤ 180，實戰最多 10,000,000，技能不超過上限……）；不認得的物品、技能拿掉並列在清單。
  外來角色**身上的銀兩加上物品的收購價合計最多 100,000 兩、最多 2 件珍品**，多的拿掉並列在清單（匯入是複製，不能把別的世界的錢與寶物整批搬進來）：
  先拿掉背包裡單價最高的東西（例：大量守護者之煙、大還丹），還超過才卸下最貴的裝備，剩下的額度才是銀兩。
  修練（打坐的氣上限加成）截到「基本內功等級 × 5 次、每次 +8 氣」；新手期雜務＋切磋已經拿過的學點（一輩子 4000）跟著角色走，換世界不會重算。
  錢莊存款、組織、進行中的任務、任務冷卻、坐牢狀態、屍體、記錄點都留在原世界；門派、袋位、善惡、殺氣、PK值、名聲、完成過的任務照帶。
- **神兵預設帶不進來**（擁有者決定 O4 改）：檔案無法驗證，偽造的檔案可以繞過全服 12 時辰的掉落鎖，所以外來角色身上的神兵一律拿掉並寫在清單。

- **再次匯入只更新成長**（擁有者決定 O12）：屬性、武功、實戰、學點、善惡等換成檔案裡的；**身上的銀兩與物品（含裝備、神兵）沿用這個世界的本地角色**，

**懸賞與律法**（`server/law_system.gd`、`core/rules/bounty_rules.gd`；WP-LAW）

- **上名單**：PK值 ≥ 4，或 PK值 ≥ 1 且善惡 ≤ −101；新手（實戰 < `newbie_pk_protect_xp`）不上。名單**每遊戲時辰統計一次**（不是即時）；

- **懸賞金**＝罰金（1000 兩 × PK值，惡人再 +500，上限 2 萬；**從被懸賞者自己身上、再從錢莊扣**，扣不到就少）＋玩家加碼的賞金池（`bounty_add`，最少 100、每人上限 10 萬，只能加給已上榜的人）。系統不憑空出錢。

- **合法緝拿**：持照對名單上的人強制 PK ＝ 不加 PK值、不扣善惡、殺氣 +20、不發全服 `pk_kill`（改成江湖傳聞）。賞金記在獵人名下，回官爺「領賞」；**真的發了賞金（> 0 兩）才**讓目標 PK值 −1——目標身上與錢莊都沒錢、也沒有加碼時賞金是 0 兩，PK值 不減（M3d 審查第三輪）。

## 執行方式

### 從編輯器

用 Godot 4.6.3 開啟專案，按 F5。主場景是 `res://ui/boot/boot.tscn`：

1. 載入 `res://data/*.json`（失敗會在畫面列出錯誤，不進遊戲）。
2. 初始化 Steam（`SteamManager` 手動呼叫 `steamInitEx(480, false)`；專案設定的自動初始化與 embed callbacks 都已關閉）。
3. 切到「江湖連線除錯」畫面（`res://ui/debug/net_debug.tscn`）：單機、開 ENet 主機、加入 ENet、開 Steam 大廳、邀請好友、搜尋大廳，以及千里傳音聊天與 Ping。

Steam 沒開或沒有載入 GodotSteam 時，Steam 按鈕會變灰，並自動進入單機模式。

### 單機

```bash
godot --path . -- --offline --world=my_world
```

### ENet：同一台電腦開兩個實例

```bash
# 主機（也是玩家）
godot --path . -- --no-steam --enet-host --port=24565 --world=lan_test --profile=host
# 客戶端（另開一個終端機）
godot --path . -- --no-steam --enet-join=127.0.0.1:24565 --profile=guest
```

`--profile` 讓同一台電腦的實例使用不同的本機身分（`<資料根目錄>/profiles/<profile>/identity.json`）。也可以在編輯器用「除錯 → 自訂執行實例」開兩個實例，在除錯畫面按「開 ENet 主機」與「加入 ENet 主機」。測試完記得關掉所有實例。

### Steam（AppID 480）

1. 兩台電腦各自開啟並登入 Steam（兩個不同帳號，互為好友）。
2. 主機：在除錯畫面按「開 Steam 大廳」（預設為好友限定大廳），再按「邀請好友」開啟 Steam 覆蓋介面邀請。
3. 好友：**先開遊戲再接受邀請**（480 冷啟動可能會開成 Spacewar，見 GDD 12.3），或從 Steam 好友清單「加入遊戲」。
4. 勾選「公開大廳」後開房，另一台可用「搜尋大廳」找到（只會列出 `game=jymini_v1` 且協定版本相同的大廳）。

也可以用參數直接開 Steam 主機：`godot --path . -- --steam-host --world=steam_test`。

完整的手動檢查清單見 `docs/TECH_ARCH.md` 15.4。

## 測試

所有測試都是無介面執行，不依賴 GUT。非 0 結束碼代表失敗。

**測試資料跟玩家的存檔分開**：所有測試（bot、`tools/*.gd`、`run_tests.gd`）沒寫 `--data-root` 時都寫在**測試根目錄**
（`DataRoot.test_root()`；開發時＝`K:\Project\JY-Mini-OL-Work\testdata\`，由專案根目錄的 `data_root.txt` 決定），不寫 `%APPDATA%`、也不碰 `JY-Mini-OL-Work\userdata\` 的開發存檔；
正常開遊戲（沒有 `--data-root`、沒有 `--bot`）看不到也不會讀這些測試世界。測試根目錄可以隨時整個刪掉，測試會自己重建。
要另外指定就加 `--data-root=<絕對路徑>`（**不要**寫 `user://…`，那會寫到 C: 的 `%APPDATA%`）。舊測試世界的處理見 `docs/TEST_WORLDS_CLEANUP.md`（只搬移、不刪除）。

```bash
# 單元測試（tests/unit 與 tests/integration 下的 test_*.gd）
godot --headless --path . --script res://tests/run_tests.gd -- --no-steam
# 只跑名稱含某字串的測試
godot --headless --path . --script res://tests/run_tests.gd -- --no-steam --filter=save

# 資料檢查（語法、必填欄位、era、交叉參照、每個 era 閉包的 activate、rule_profiles 開關齊全）
godot --headless --path . --script res://tools/data_lint.gd -- --no-steam
# 同上（別名）
godot --headless --path . --script res://tools/validate_data.gd -- --no-steam

# 平衡模擬（M1_PLAN 6.3）：參考角色對各怪物對打 500 次，檢查勝率與傷害區間
godot --headless --path . --script res://tools/balance_sim.gd -- --no-steam --runs=500

# 連線冒煙：自動開 1 個 ENet 主機 + 2 個 bot 客戶端，驗證聊天經主機轉送
godot --headless --path . --script res://tools/net_smoke.gd -- --no-steam
```

### M1 驗收 bot（M1_PLAN 6.4）

從創角一路玩到鬼王：創角、大兔皮任務、記錄點、練功、釣魚、驛站送信走到大理（確認坐車被拒 `stagecoach_disabled`、經過綠洲、酬勞 100 兩＋聲望 2）、種田與種稻任務、廚師、送信走回西夏、
東路走到少林拜師與學武、齋食、經血刀洞口進血刀洞迷宮戰鬥、重新選角與存檔檢查。全程用走的；要休息就去最近的客棧／茶棚／綠洲。
bot 只透過 `NetworkManager.send_intent()` 與 `ClientState` 互動，一次只送一個 intent。

```bash
godot --headless --path . -- --no-steam --offline --world=w2001_accept --profile=m1bot       --bot=res://tests/bots/m1_playthrough_bot.gd --time-scale=50 --quit-after=1800
```

第 23 步會在血刀洞迷宮只按「防」撐到死亡，依世界的 death_rule 斷言懲罰。三種死亡規則各跑一次（各用新的世界名）。
同一個世界裡角色名字已被**別的 profile** 用掉時創角會 `name_taken`（舊存檔造成）：換一個新的世界名即可。

```bash
godot --headless --path . -- --no-steam --offline --world=w2001_accept_std    --rule-preset=classic_standard --bot-expect-rule=STANDARD    --profile=m1bot --bot=res://tests/bots/m1_playthrough_bot.gd --time-scale=50 --quit-after=1800
godot --headless --path . -- --no-steam --offline --world=w2001_accept_strict --rule-preset=classic_strict   --bot-expect-rule=STRICT_2001 --profile=m1bot --bot=res://tests/bots/m1_playthrough_bot.gd --time-scale=50 --quit-after=1800
godot --headless --path . -- --no-steam --offline --world=w2001_accept_casual --rule-preset=friends_casual   --bot-expect-rule=CASUAL      --profile=m1bot --bot=res://tests/bots/m1_playthrough_bot.gd --time-scale=50 --quit-after=1800
```

走主機權威的網路路徑（無介面專用主機 + bot 客戶端；客戶端不檢查主機上的存檔檔案）：

```bash
godot --headless --path . -- --no-steam --dedicated --enet-host --port=24600 --world=m1_net --time-scale=50 --quit-after=1860
godot --headless --path . -- --no-steam --enet-join=127.0.0.1:24600 --profile=m1net --bot=res://tests/bots/m1_playthrough_bot.gd --quit-after=1800
```

成功印 `M1_ACCEPT_OK`、結束碼 0；bot 腳本載入失敗（語法錯誤）立即以結束碼 2 結束；某一步失敗印 `M1_ACCEPT_FAIL step=<n> <原因>`、結束碼 2；逾時（`--quit-after`）結束碼 1。
bot 每次開始都會刪掉此 profile 在該世界裡的舊角色。

### M2 驗收（M2_PLAN 6.2、6.3）

`tools/m2_acceptance.gd` 開 1 個 ENet 專用主機（`classic_strict`、`newbie_pk_protect_xp=0`、`encounters_enabled=false`（路上不踩地雷，免得隨機死亡卡住柵欄）、`--time-scale=5`）＋ 4 個 bot（`tests/bots/m2_party_bot.gd`：隊長、隊員、狂徒、路人），
bot 之間只用檔案柵欄同步（`<測試根目錄>/m2_acceptance/<run>/sync/`），聊天本身是受測物：

1. 建角、組 4 人隊（路人第一次拒絕、再邀才接受）；隊伍頻道（扣水）、密語（只有對象收到）、謠言（其他人看到匿名）。
2. 4 人走到草坡，隊長、隊員、狂徒上狼嚎丘；路上遇敵就打，同房隊友的戰鬥能加入就加入、單人遇到野狼就逃。
3. 隊長找山賊頭目開打，隊員與狂徒沒送 intent 就被拉進同一場（bid 相同）；路人收到開打的柵欄後才上丘、`battle_join` 中途加入；打贏，活著的人都有實戰（印出每人分到的實戰）。輸了或路人沒趕上就重來（最多 3 次）。
4. 狂徒離隊，全員到東門外官道（可 PK）：叫戰被拒（`challenge_declined`）、隊長關「接受叫戰」後再叫戰得 `challenge_refused`。
5. 狂徒強制 PK 路人：雙方 `kind == FORCED`、路人 `my_side == 1`；路人只按「防」到死；狂徒 PK值 1、殺氣 +100、善惡 −10，全員收到 `pk_kill`；隊長看得到屍體。
6. 狂徒撿屍被擋（`corpse_protected`）；路人授權隊長，隊長在保護期內單件撿走 1 件（`corpse_looted_other`／`corpse_looted_by`，件數減少）。
7. 隊員離線；隊長寄信給離線的隊員、路人寄信給在線的隊長（`mail_arrived`、未讀 1 → 讀信）。
8. 主機以 `--stop-file` 關閉 → 檢查 `world.json` 有那具屍體與兩封信 → 同參數重開 → bot 每 2 秒 `reconnect()`：隊伍已解散、PK值、善惡、殺氣、屍體（同 id 同件數）、信件已讀、世界日期都恢復；隊員重新上線收到 `mail_waiting n=1` 並讀信。

```bash
godot --headless --path . --script res://tools/m2_acceptance.gd -- --no-steam [--timeout=1500] [--time-scale=5]
```

成功印 `M2_ACCEPT_OK`、結束碼 0（實測約 30–110 秒，看路上遇敵與頭目戰死了幾個人）；失敗印 `M2_ACCEPT_FAIL <原因>` 並傾印各 log 尾端，結束碼 1。
各程序的 log 在 `<測試根目錄>/m2_acceptance/<run>/*.log`，`world_after_stop.json` 是關服當下的世界存檔備份。不論成敗，所有子程序都會 `OS.kill()`。

### 故事驗收（STORY_PLAN §9.2）

`tools/story_acceptance.gd` 把工作分給數個 worker 子行程（同一個檔案帶 `--story-worker`）。每個 worker 在自己的行程裡開真的主機（`WorldServer`＋`GameHost`、全部系統、`--debug-intents`），
玩家是假的遠端連線（跟主機端整合測試同一套 `ClientState.capture_remote`），一切動作都經 `handle_intent`：

1. **每條任務的每一條 `test_plan`**（WP-MERGE 原樣存在 `data/quests.json` 的任務列；每個結局至少一條，另有碎片寫的失敗／重試分支）各用**全新世界、新角色**（出生城西夏、大理輪流）跑一次：
   `tests/bots/story_bot.gd` 照路徑走（`walk@` 用區域圖找路、一步一步 `move`，路上遇敵就打）、交談、選選項、房間動作、戰鬥（WIN／FLEE／DEFEAT）、買東西、等時辰／等天數。
   路徑沒寫的接任務門檻：前置任務（`quest_done`）照它自己的 `test_plan` 先走完；旗標、武功、屬性門檻用 `debug_set`；門派直接設定（`debug_set` 沒有門派鍵）。bot 角色一律加強（屬性 150、基本武功 120、實戰 400），每場戰鬥前回滿。
2. 中途**存檔 → 關主機 → 同一世界重開 → 重新選角 → 繼續**（`save_reload_at` 或預設第 2 個階段；要在沒有開著的對話、不在戰鬥時），進行中的狀態（階段、目標、變數、護送）必須一模一樣，護送的 NPC 還在畫面上。
3. 檢查：每個走過的階段都有 `quest_stage`、`quest_complete` 的結局名與 `done.outcome`、獎勵（以任務的 `reward` 事件加總，不受路上戰鬥影響）、物品增減、旗標、武功等級與熟練、傳聞；
   一次性任務完成後選單是「已完成」且不能再接，可重複任務是「冷卻中」、快轉冷卻後可以再接。
4. `duo`（`tests/bots/story_duo_bot.gd`，同一個主機兩個玩家）：雲兒一人選阿寶、一人選李台安，兩人結局各自正確，「全服第一位」傳聞只發一次；
   劉二爺（下）甲先到秘密客階段時只有甲看得到秘密客；乙單獨被伏擊打輸（不算完成）後，甲對暗語開打把同隊的乙拉進同一場，打贏後兩人都完成伏擊目標，各自回報完成。
5. `ambient`：白天葉二娘對善惡 0 不出手、對善惡 > 0 交談即戰（可逃），南海鱷神交談即戰；戌時南海鱷神放到下一間野外房間 → 走進去收到警告 → 不動 → 追擊戰、逃跑被拒 → 打贏；
   葉二娘警告時離開房間 → `ESCAPED`、不開打；實戰 0 的新手走進惡人所在的房間不被出手；`rumor_list` 有回應。

```bash
godot --headless --path . --script res://tools/story_acceptance.gd -- --no-steam [--all] [--chain=q_yuner[,q_xuzhu]] [--branch=abao] [--only=duo|ambient|chains] [--workers=4] [--timeout=3600]
```

不帶參數（或 `--all`）跑全部（目前 96 條路徑＋duo＋ambient，約 20 秒）；`--chain`、`--branch`（比對 `test_plan` 的 `outcome` 與 `branch`）只跑指定的。
成功印每條的 `PASS` 列（耗時、存檔重載次數、走了幾步、打了幾場）與 `STORY_ACCEPT_OK`、結束碼 0；任何一條失敗、worker 的 log 有 SCRIPT ERROR、或全部跑時有結局沒有任何 `test_plan`，印 `STORY_ACCEPT_FAIL`、結束碼 1。
log 與測試世界在 `<測試根目錄>/story_acceptance/`；不論成敗，所有子程序都會 `OS.kill()`。

### 主機端整合測試

`tests/unit/test_world_*.gd` 用真正的 Autoload 與 `res://data` 以離線模式跑完整的 intent 路徑（角色、移動、NPC、任務、戰鬥、死亡規則矩陣、生活技能）；
共用基底是 `tests/unit/test_world_fixture.gd`。

`net_smoke.gd` 會記下每個子程序的 pid，結束時（含失敗與逾時）一律 `OS.kill()`；子程序也都帶 `--quit-after`。子程序的 log 在 `<測試根目錄>/net_smoke/*.log`。
如果手動測試後懷疑有殘留程序，PowerShell 可用 `Get-Process Godot*` 檢查、`Stop-Process -Name Godot*` 關閉。
